# URL Scaler

A lightweight, zero-dependency command-line URL shortener written in pure Go. It creates an isolated local HTTP server in a background thread and generates a unique 6-character short code that redirects your short link in real time.

## Built With

![Go](https://img.shields.io/badge/Go-1.22-00ADD8?logo=go&logoColor=white)

## Getting Started

### Pre requisites

Install Go on your system using your package manager or the official installer:

- **macOS:** `brew install go`
- **Linux:** `sudo apt install golang-go`
- **Windows:** Download and run the installer from [go.dev/dl](https://go.dev/dl/)

Verify the installation:

```bash
go version
```
git clone [https://github.com/Kartik-K-Kumar/URL-Scaler.git](https://github.com/Kartik-K-Kumar/URL-Scaler.git)
cd URL-Scaler

## **Usage**
```go run main.go```
add a URL you would like to shrink and click "Enter"
