# URL Scaler
A lightweight, zero-dependency command-line URL shortener written in pure GO. It creates an isolated local HTTP server in a background thread and generates a unique 6-character short code, which redirects your short link in real time.

## Built With

* [Go](https://go.dev/)

## Getting Started

### Prerequisites (Installing Go)

Install Go on your system using your package manager or official installer:

* **macOS**: `brew install go`
* **Linux**: `sudo apt install golang-go`
* **Windows**: Download and run the installer from [go.dev/dl](https://go.dev/dl/)

Verify installation:
```bash
go version

git clone [https://github.com/Kartik-K-Kumar/URL-Scaler.git](https://github.com/Kartik-K-Kumar/URL-Scaler.git)
cd URL-Scaler
'''

## **Usage**
'''
go run main.go
'''
add a URL you would like to shrink and click "Enter"
